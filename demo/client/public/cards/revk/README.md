# RevK playing-card assets

Эта папка содержит 52 SVG-лица карт и `BACK.svg`, которые основной игровой стол загружает по пути `/cards/revk/<CODE>.svg`.

Формат кода карты:

- ранг: `2`–`9`, `T`, `J`, `Q`, `K`, `A`;
- масть: `C`, `D`, `H`, `S`;
- пример: `QD.svg`.

Лица карт сгенерированы на [me.uk/cards](https://www.me.uk/cards/) с параметрами:

- poker size;
- normal indices;
- top index only;
- classic red and black suits.

Original artwork: Adrian Kennard (RevK), CC0 1.0 Universal.

`BACK.svg` — отдельная проектная рубашка и не относится к исходному набору RevK.
