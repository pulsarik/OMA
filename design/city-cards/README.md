# Коллекционные карточки столиц

Этот каталог изолирован от игрового клиента и сервера. Карточки здесь — самостоятельные дизайн-ассеты и не подключаются к основной логике приложения.

## Фиксированный шаблон серии

- Формат: вертикальный 4:5, скруглённая рамка, светлый фон с полупрозрачным мотивом флага.
- Верх: крупное название столицы, страна акцентным цветом, малый флаг справа.
- Главный блок: достопримечательность слева, карта страны со столицей справа.
- Нижняя сетка: население, структура ВВП, религия, интересный факт.
- Цвета ВВП: зелёный — сельское хозяйство, синий — промышленность, жёлто-оранжевый — услуги.
- Для новых столиц меняются только локальные данные и иллюстрации; композиция, размеры блоков и типографическая иерархия остаются неизменными.
