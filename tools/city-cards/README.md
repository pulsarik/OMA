# Генератор карточек столиц

Изолированный от приложения генератор SVG-карточек. Он не использует API и не требует npm-зависимостей.

```powershell
node tools/city-cards/generate.mjs
```

- `cities.mjs` — изменяемые данные, карта, порты и тип достопримечательности.
- `template.mjs` — единая композиция и визуальная система серии.
- `output/` — готовые масштабируемые SVG.
- `gallery.html` — адаптивная галерея примеров.

Чтобы добавить столицу, добавьте объект в массив `cities`. Существующая сетка карточки останется неизменной.
