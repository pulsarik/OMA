# Новый овальный стол: мобильный и настольный

Опциональный интерфейс по согласованному макету: овальное зелёное сукно,
спокойный золотой кант, соперники вокруг стола, собственная рука снизу.
На десктопе стол горизонтальный, подсказки HIGH/LOW и действия расположены
в общей нижней панели. Рекламы нет. Обе раскладки включаются одним флагом.
Четыре карты каждого игрока видны одновременно на вскрытии. До вскрытия
показываются только собственные карты и рубашки соперников.

## Включение

В `demo/client/.env.local` добавьте:

```dotenv
VITE_MOBILE_TABLE_UI=true
```

Перезапустите Vite. Для production переменную нужно задать **при сборке клиента**:
Vite встраивает значение в JavaScript. Изменение окружения уже запущенного Node-сервера
без пересборки клиента не переключает интерфейс. По умолчанию флаг выключен.

Разовый запуск из корня репозитория в PowerShell:

```powershell
$env:VITE_MOBILE_TABLE_UI = 'true'
npm.cmd --prefix demo/client run dev
```

Сервер запускается штатно (`npm.cmd --prefix server run dev`). Для просмотра
нужна страница игрока либо запущенная игра в лобби.

## Границы

- Мобильный интерфейс (до 760 px включительно): 2–7 игроков.
- Настольный интерфейс (шире 760 px): 2–10 игроков, в том числе макет на 8 мест.
- При включённом флаге мобильный выбор размера нового стола ограничен семью местами.
- На мобильном существующие столы на 8–10 игроков используют прежний экран.
- При выключенном флаге на всех размерах экрана остаётся прежний интерфейс.
- На коротких экранах допускается вертикальная прокрутка: карты не уменьшаются до нечитаемого размера.
- EN/RU переключается в меню мобильного стола или в настольной шапке; выбор запоминается.
- Статистика и правила доступны через мобильное меню или настольную навигацию и используют существующие страницы; вкладка TABLE возвращает новый стол.

## Состояния

Отображаются D/SB/BB, стеки, ход и таймер, последнее действие, fold, all-in,
offline, выбывшие игроки, replay и предупреждение об истечении сессии.
Ставки используют существующие расчёты/ограничения и надёжную отправку команд из PlayerPage.
Во время ожидания подтверждения и при потере связи кнопки блокируются.
All-in требует подтверждения.

На вскрытии у **каждого** победителя выводятся его HIGH/LOW-выплаты и рамка
вокруг всей руки. Под собственной рукой постоянно зарезервированы две подсказки:
название комбинации, две карты руки и три карты борда с подписями источников.
Комбинации и выплаты берутся из серверного снимка, клиент их не оценивает.
Выплата и чистый итог раздачи показаны раздельно.
Побочные банки, состав участников и выплаты доступны в «Банки и результаты».
В конце партии показаны победитель/статистика и доступные ведущему действия.

## Изоляция и проверки

Компоненты, CSS, локализация и контракт представления находятся в
`demo/client/src/mobile-table/`. Модуль загружается лениво. В `App.tsx` добавлены
выбор рендера и передача данных/callbacks; правила и WebSocket-протокол не менялись.

```powershell
npm.cmd --prefix demo/client run typecheck
npm.cmd --prefix demo/client run build
npm.cmd --prefix demo run test:client -- --runInBand
npm.cmd --prefix demo run e2e:mobile
```

Браузерные проверки запускают собственный Vite на 5187 с флагом, используют сервер
на 4000 и сохраняют снимки экрана в игнорируемый `demo/test-results/`.
Проверяются все размеры стола, геометрия на 320–540 px, ничьи HIGH/LOW, скрытие
карт, all-in, подтверждения, переход на следующую раздачу и настоящий сценарий лобби.
Настольная геометрия проверяется на 761, 1024, 1440 и 1920 px для 2–10 игроков
во время игры и на вскрытии, включая переходы между раскладками при изменении окна.
